# Як це влаштовано

[English](../en/overview.md) · [Усі сторінки](../README.md)

SlipDrukka друкує з програм на Windows Server на принтери в магазинах через
інтернет. На роутерах магазинів нічого не налаштовується, а чек малює драйвер
на сервері.

```
Сервер (Windows Server)                       Магазин (Windows 10/11)
  програма (облік, каса…)                       slipdrukka-agent (служба)
    → принтер Windows з драйвером моделі          → принтер Windows
    → порт 127.0.0.1:91xx                         → USB або мережа
    → slipdrukka-server (служба)  ◄── тунель ───  магазин сам підключається
```

Дві програми:

* **Сервер** (`slipdrukka-server`) стоїть на Windows Server поруч із
  програмами, з яких друкують. У нього є панель керування в браузері — усе,
  що описано в цій вікі, крім сторінки магазину.
* **Точка** (`slipdrukka-agent`) стоїть на комп'ютері в магазині. Вона сама
  підключається до сервера і друкує те, що він надсилає. Її власна сторінка
  лише показує стан.

## Шлях одного чека

1. Касир натискає «Друк» у програмі на сервері. Програма друкує на звичайний
   принтер Windows, наприклад «Вокзальна XP-80C».
2. Драйвер моделі на сервері малює чек (текст, QR, штрихкод) і віддає його в
   порт `127.0.0.1:9101`. Цей порт слухає SlipDrukka.
3. Сервер спершу записує чек на диск, і лише тоді Windows чує «надіслано».
4. Сервер передає чек точці «Вокзальна» через тунель: WireGuard, якщо він
   проходить, інакше звичайне шифроване з'єднання TLS.
5. Точка віддає чек у принтер Windows магазину без змін. Сервер видаляє чек
   зі своєї черги лише після того, як точка підтвердила друк.

Якщо магазин без інтернету, чек чекає на сервері й надрукується, щойно
зв'язок повернеться. Застарілі чеки прибираються (див.
[Налаштування → Черга чеків](settings.md#черга-чеків)).

## Що де відкривати

| Що | Де | Хто |
|---|---|---|
| Панель сервера | `http://127.0.0.1:7330` на самому сервері (по RDP) | адміністратор |
| Сторінка магазину | `http://127.0.0.1:7320` на комп'ютері магазину або значок біля годинника | будь-хто в магазині, лише перегляд |

## Приклад: перший магазин за 10 хвилин

1. На сервері: встановіть `slipdrukka-server-X.Y.Z.msi`, прокиньте на
   роутері сервера порт 7310 (TCP і UDP).
2. Відкрийте панель, у [Налаштуваннях](settings.md) вкажіть зовнішню адресу,
   наприклад `relay.example.com:7310`.
3. [Додайте магазин](add-shop.md) — панель дасть команду встановлення з кодом.
4. Виконайте цю команду на комп'ютері магазину. За кілька секунд магазин
   з'явиться в панелі «на зв'язку».
5. [Додайте принтер](add-printer.md) магазину, потім
   [створіть для нього принтер на сервері](server-printer.md).
6. Надрукуйте тестову сторінку з будь-якої програми на сервері.
